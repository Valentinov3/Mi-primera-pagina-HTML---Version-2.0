# Mi-primera-pagina-HTML---Version-2.0
Trabajo educativo que recrea la pagina inicial de MercadoLibre Colombia usando solo HTML5 y CSS, sin JavaScript. Es la continuacion del primer ejercicio, donde se hizo el clon con HTML puro. En este caso se agrega CSS para mejorar el diseno y se compara el resultado con el de otra herramienta de inteligencia artificial.
